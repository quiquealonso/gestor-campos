# Gestor Campos · front

App Angular 20 de [Gestor Campos](../README.md). Instrucciones completas en el README principal.

```bash
npm install
npm start            # http://localhost:4200, con tu Supabase (src/enviroments/environment.local.ts)
npm run demo         # http://localhost:4300, modo demo con datos ficticios (sin Supabase)
npm test             # tests unitarios (Karma)
npm run build:demo   # demo para GitHub Pages en ../docs/demo
npm run apk          # APK Android en ../GestorCampos.apk (necesita Android Studio)
npm run electron-build  # .exe portable de Windows en dist-electron/
```
