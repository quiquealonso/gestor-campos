06Empezar

Tu propia copia, en cinco pasos

  1. Crea un proyecto en Supabase, desactiva el registro abierto y crea tu usuario.
  2. Ejecuta supabase/schema.sql en el SQL Editor y autoriza tu email en la tabla propietario.
  3. Copia environment.ts a environment.local.ts con tu URL y tu clave publishable.
  4. Instala y arranca el front, o la demo sin Supabase.
  5. Genera el APK con Android Studio instalado.
~/gestor-campos
# 1-2 · en el SQL Editor de Supabase
sql> insert into public.propietario (email)
      values ('tu-email@ejemplo.com');

# 3 · configuración local (ignorada por git)
$ cp front/src/enviroments/environment.ts \
     front/src/enviroments/environment.local.ts

# 4 · arrancar
$ cd front && npm install
$ npm start        # localhost:4200 · tu Supabase
$ npm run demo     # localhost:4300 · datos ficticios

# 5 · app Android
$ npm run apk      # → GestorCampos.apk
